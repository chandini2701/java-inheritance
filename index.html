Java Inheritance

Learn how one class can acquire the properties and methods of another class with simple explanations and examples.

1. What Is Inheritance?

Inheritance is an important feature of Object-Oriented Programming (OOP). It allows one class to acquire accessible fields and methods from another class.

The class whose features are inherited is called the parent class, superclass, or base class. The class that inherits those features is called the child class, subclass, or derived class.

Remember: In Java, the keyword extends is used for class inheritance.

2. Why Do We Use Inheritance?

  • Code reusability: reuse existing methods and fields.
  • Reduces code duplication.
  • Makes programs easier to maintain.
  • Supports method overriding and runtime polymorphism.
  • Helps create logical relationships between classes.

3. Important Terminology

Parent Class

A class that provides accessible members to a child class.

Child Class

A class that extends another class and inherits its accessible members.

extends

The Java keyword used to inherit from a class.

super

Used to refer to superclass members and invoke superclass constructors.

4. Types of Inheritance in Java

1. Single Inheritance

One child class inherits from one parent class.

Animal → Dog

2. Multilevel Inheritance

A class inherits from a child class, forming multiple levels.

Animal → Dog → Puppy

3. Hierarchical Inheritance

Multiple child classes inherit from the same parent class.

Animal → Dog
Animal → Cat

4. Multiple Inheritance

A class inherits from multiple parents. Java does not support multiple inheritance through classes, but it supports implementing multiple interfaces.

Interface A + Interface B → Class C

5. Hybrid Inheritance

A combination of two or more inheritance types. Java can model hybrid inheritance using interfaces, since multiple inheritance of classes is not allowed.

5. Rules of Inheritance

  • A Java class can directly extend only one class.
  • Constructors are not inherited.
  • Private members cannot be accessed directly in a child class.
  • Public and protected members are accessible according to Java access rules.
  • Package-private members are accessible only within the same package.
  • Final classes cannot be extended.
  • Static methods are hidden, not overridden in the usual polymorphic sense.
  • Every Java class except Object ultimately has Object as an ancestor.

6. Inheritance vs. Encapsulation

Inheritance allows a class to reuse or extend another class's behavior. Encapsulation bundles data and methods together and controls access to an object's internal state.

7. Java Program Example

In this example, the Dog class inherits the eat() method from the Animal class and defines its own bark() method.

InheritanceExample.java 
class Animal {
    void eat() {
        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog is barking");
    }
}

public class InheritanceExample {
    public static void main(String[] args) {
        Dog d = new Dog();

        d.eat();
        d.bark();
    }
}

Output

Animal is eating
Dog is barking

How Does It Work?

  1. Animal is the parent class.
  2. Dog extends Animal makes Dog a child class.
  3. eat() is defined in Animal.
  4. bark() is defined in Dog.
  5. The object d can call both accessible methods.

8. Advantages and Disadvantages

Advantages

  • Code reuse
  • Less duplication
  • Easier extension
  • Supports polymorphism

Disadvantages

  • Tight coupling between classes
  • Changes to parent classes may affect children
  • Deep hierarchies can be difficult to understand
